# Weekend Dev Blog

Lovable can you create me a minimalist blog, the blog is left aligned, a logo on the top left corner that says The Weekend Developer in 3 lines, the top of the stack is the word "The" Second is "Weekend" and then "Developer" It should be in a typewriter font. Below it immediately is the title of the first post in an elegant Merriweather font with font size of 40px then I will let you decide which sans-serif font will go well with Merriweather. Below the title is a small sans-serif font for date and category.
